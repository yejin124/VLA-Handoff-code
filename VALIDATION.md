# Validation scope — 10 November 2026

The public package is a source distribution without experimental result files. Its collection grid contains 30 configurations totaling 10,752 episodes. Original and corrected robot-state conventions are separately preserved. Fixed occluder textures, recorded environment/checkpoint versions and an official GR00T source revision are included as reproduction inputs.

Validation checks cover 62 passing CPU regression tests in a freshly installed Python 3.11 environment, parsing and compilation of Python sources, command generation for every cohort, local documentation links, clean-package schematic generation, numeric/prefix/provenance rejection paths, new-cohort support and missing-input handling, table and figure generation from supplied analyses, complete protocol-cell checks for the compact supplementary tables, and recomputation of primary predictions from the retained original raw records. SmolVLA's two baseline fits also match with and without an external historical result file. The pinned CPU dependencies pass `pip check`. Exact execution details are recorded in the author workspace's submission audit.

The CPU test suite uses synthetic examples and temporary files; those examples are not paper measurements. Baseline tests establish that published result JSON is no longer required. Model and simulator installation, all 10,752 closed-loop trajectories, intervention GPU replay, and every 2,000-draw bootstrap were not repeated during this packaging check. Whole-project line coverage was not measured. J64 preparation uses the active-query count in a validated collection, with prefix and runtime checks. Archival J64 replay still requires the original inputs and matching runtime. The clean official GR00T source exposes the required measurement hooks, but its GPU inference equivalence to the original local source has not been tested. The earlier single-trajectory DROID study and archived sampling-repeatability inputs are outside this source distribution.

Run `python -m unittest discover -s tests -v` and `sha256sum -c SHA256SUMS.txt` from an unmodified unpacked package. Hashes describe the distributed source/input files; generated data and local configuration are intentionally ignored by Git.
